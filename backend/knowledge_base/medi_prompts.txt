Critical Fixes (would have broken the app or harmed users)                             ✗ FIXED: Critical 1 — No medical disclaimer on doctor cards                Every doctor card and the DoctorSuggestions component now includes a mandatory safety banner and per-card disclaimer. The Groq LLM can hallucinate hospital names. Users must know suggestions are AI-generated.                             ✗ FIXED: Critical 2 — Google Maps URL broke for cities with special characters                Changed to encodeURIComponent() wrapping the full search string. &apos;Dera Ghazi Khan&apos; and international city names now produce valid URLs that open correctly in Google Maps.                             ✗ FIXED: Critical 3 — Supabase RLS policies were underspecified                Exact SQL for all 3 RLS policies is now hardcoded in the prompt using auth.uid() server-side. Copilot is told not to generate its own policies. This prevents any user from reading another user&apos;s diagnoses — a GDPR violation for a public app.                             ✗ FIXED: Critical 4 — AuthModal used position:fixed (collapses on mobile)                The modal now uses a full-height wrapper div with flexbox centering. No position:fixed anywhere. Works correctly on all mobile browsers and in all rendering environments.                           Warnings Fixed (bad practice for open source / public app)                             ✗ FIXED: Warning 1 — Race condition when saving doctors                The diagnosis Supabase insert now uses .select() to return the inserted row id. The diagnosis_id is stored in state only after the insert resolves. Doctor saves only become available after the id exists.                             ✗ FIXED: Warning 2 — Hallucinated hospitals stored as permanent facts                The saved_doctors table now has an is_ai_suggested boolean column (default true). The profile page shows a &apos;Verify before visiting&apos; badge on every AI-suggested saved doctor.                             ✗ FIXED: Warning 3 — Unverified email users could access the full app                Auth flow now checks email_confirmed_at. Unverified users see only a confirmation screen, not the triage system. The 1122 emergency number is shown even on the confirmation screen for safety.                             ✗ FIXED: Warning 4 — total_diagnoses was incremented client-side (drift on network failure)                Replaced with a Supabase database trigger. The count is now always accurate regardless of network conditions, page reloads, or multiple sessions.                             ✗ FIXED: Warning 5 — No validation on chronic_conditions and allergies fields                Tag input pattern with Enter/comma to add. Maximum 10 tags, 50 chars each. Input is trimmed and lowercased before saving. Prevents garbage data in the health profile.
